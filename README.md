# Tips & Tricks

**Useful ways to make computers easier to use.**

A growing, practical collection of shortcuts, workflows, commands, discoveries, and small techniques that save time or eliminate repetitive work.

This is a field guide, not a framework or a rulebook. Take what is useful, adapt it, and contribute improvements.

## Start here

- **[TIPSANDTRICKS.md](TIPSANDTRICKS.md)** — the main searchable cheat sheet and workflow glossary.

## What belongs here?

Anything that makes a recurring task easier:

- Copy terminal output automatically.
- Keep exported screenshots, videos, audio, and project files.
- Move files between computers and phones.
- Recover a previous terminal session or development task.
- Automate repetitive application interactions.
- Capture, compare, and inspect software behavior.
- Download, convert, resize, or identify media.
- Diagnose common computer, browser, printer, and audio problems.
- Turn a multistep process into a short reusable recipe.

Tips can be tiny one-liners or complete multistep workflows. Prefer practical examples over abstract advice.

## How to contribute

A useful entry usually answers:

1. **When is this useful?**
2. **What do I do?** Include a command, shortcut, or short sequence when possible.
3. **What should happen?**
4. **What are the limitations?** Mention operating system, application version, permissions, or setup requirements.

Please distinguish:
- **Tested:** actually run and observed.
- **Setup-specific:** worked in a particular environment; names and paths may differ.
- **Idea:** useful approach that still needs testing.

Keep entries concise. Improve an existing tip rather than adding a duplicate. Never include passwords, API keys, private tokens, personal data, or machine-specific secrets.

## Philosophy

The best tricks are often small: one command that copies its own result, one reliable way to preserve a video, one sequence that recovers a remote session, or one shortcut that saves ten minutes every day.

Collect the useful things. Make them easy to find. Share them so other people do not have to rediscover them.
